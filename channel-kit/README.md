# Unchased channel kit (saved for later production)

- `hero.jpeg`, `sheet.jpeg`, `avatar.jpeg`, `logo.jpeg`, `banner.jpeg`: identity images extracted from the kit. `hero.jpeg` is the reference for every scene that shows the character.

Style: flat 2D cartoon, thick black outlines, warm off-white `#FBF8F2`, ink `#17140F`, burnt orange `#C8541A` as the only accent (green `#2F7D4F` only for the woman's coat).
